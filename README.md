This project analyzes 2.3M+ banking transactions to understand customer behavior, transaction patterns, and value distribution. The goal 
is to build a data-driven customer segmentation framework for business decision-making.


🎯 Objectives
Analyze transaction behavior across channels and time
Engineer behavioral features from raw banking data
Segment customers using RFM (Recency, Frequency, Monetary) analysis
Identify high-value (VIP) customers
Understand revenue concentration and customer value distribution

🛠 Methods Used
Python (Pandas, NumPy)
Feature Engineering
Exploratory Data Analysis (EDA)
RFM Analysis
Customer Segmentation
Data Visualization

📊 Key Insights
A highly skewed revenue distribution was observed across customers
Champions segment contributes disproportionately higher monetary value (~2.4M average)
Majority of customers fall into “At Risk” segment
Strong evidence of Pareto-like (80/20) revenue distribution in banking behavior
Significant upselling opportunity exists in “Potential Loyalists” segment

📈 Visualizations
Customer segment distribution
Revenue contribution by segment
Average customer value per segment
Behavioral segmentation analysis

💡 Business Impact
Enables identification of high-value customers
Supports targeted marketing strategies
Helps optimize retention strategies for at-risk customers
Provides foundation for customer lifetime value modeling
